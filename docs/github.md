## Короткое описание

Русский:

```
Пульт дрона или FPV-аппаратура как геймпад Xbox 360 для игр без поддержки пульта: USB-джойстик и приёмник ExpressLRS по CRSF, калибровка, профили, установка ViGEmBus из программы. Русский и английский интерфейс, готовый exe.
```

Английский:

```
A drone or FPV radio as an Xbox 360 gamepad for games without radio support: USB joystick and ExpressLRS receiver over CRSF, calibration, profiles, ViGEmBus setup from the app. Russian and English UI, ready-made exe.
```
